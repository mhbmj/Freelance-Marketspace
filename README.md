# پلتفرم بازار کار فریلنسری (Freelance Marketplace)

این پروژه در چارچوب درس **آزمایشگاه مهندسی نرم‌افزار** (مدرس: مهندس میهن‌پور) طراحی و پیاده‌سازی شده است.

* **نام تیم:** مهتاب
* **عضو تیم:** مهتاب مروج

---

## ۱. معرفی کلی سامانه

پلتفرم **Freelance Marketplace** سامانه‌ای برای ارتباط کاری میان کارفرمایان و فریلنسرها است. این مخزن شامل دو فاز اصلی است:
1. **فاز پایگاه داده (Assignment 02):** طراحی کامل جداول رابطه ای، کلیدها، محدودیت‌ها، تریگرها و نمودار ERD.
2. **فاز احراز هویت و فرم‌ها (Assignment 03):** پیاده‌سازی کامل صفحات ورود (Login)، ثبت‌نام (Sign Up)، بازیابی رمز عبور.

---

## ۲. فاز احراز هویت، ثبت‌نام و بازیابی رمز عبور (Assignment 03)

این بخش با استفاده از فریم‌ورک پایتون / جنگو (Django) پیاده‌سازی شده است.

### ویژگی‌های پیاده‌سازی‌شده مطابق مشخصات تکلیف:
* **صفحه ورود (Login):**
  * فیلدهای ایمیل، رمز عبور و دکمه ورود
  * دکمه چشم برای **نمایش / مخفی‌سازی رمز عبور** (Show/Hide Password)
  * لینک به ایجاد حساب جدید و بازیابی رمز عبور
  * **پیام خطای امن و خنثی:** در صورت ورود ناموفق، پیام *«ایمیل یا رمز عبور اشتباه است»* نمایش داده می‌شود تا مشخص نشود کدام مورد نادرست بوده است.
  * انتقال به صفحه خوش‌آمدید پس از ورود موفق و حفظ نشست (Session).

* **صفحه ثبت‌نام (Sign Up):**
  * فیلدهای نام، نام خانوادگی، ایمیل، شماره موبایل (اختیاری)، رمز عبور و تکرار رمز عبور
  * بررسی یکسان بودن رمزها و حداقل ۶ کاراکتر بودن
  * **جلوگیری از ثبت ایمیل تکراری** با پیام خطای مشخص
  * **هش امن رمز عبور در سمت بک‌اند:** استفاده از الگوریتم استاندارد **PBKDF2 (با SHA-256)** و عدم ذخیره رمز خام یا استفاده از هش‌های ضعیف

* **صفحه بازیابی رمز عبور (Forgot Password):**
  * ثبت درخواست با ایمیل
  * **عدم افشای وجود یا عدم وجود ایمیل:** نمایش پیام یکسان برای ایمیل‌های موجود و ناموجود جهت حفظ حریم خصوصی
  * تولید **لینک زمان‌دار (۳۰ دقیقه)**، امن و **یک‌بار مصرف (Single-use)**
  * ارسال ایمیل به کنسول خط فرمان (`Console Email Backend`) جهت تست آسان در محیط توسعه
  * فرم تعیین رمز عبور جدید و ورود با رمز جدید پس از تغییر

* **صفحه خوش‌آمدید (Welcome):**
  * صفحه محافظت‌شده (`@login_required`) که بدون لاگین در دسترس نیست
  * نمایش نام و نام خانوادگی، آدرس ایمیل، شناسه کاربری و وضعیت نشست
  * دکمه خروج از حساب (Logout) که نشست را پایان داده و به صفحه ورود هدایت می‌کند.

## ۳. راهنمای اجرای برنامه احراز هویت

برای اجرای برنامه کافی است مراحل زیر را در ترمینال انجام دهید:

### ۱. اجرای مایگریشن‌ها و ایجاد پایگاه داده
```bash
python manage.py migrate
```

### ۲. (اختیاری) ایجاد کاربران نمونه تستی
برای ایجاد کاربران آماده تستی با یک دستور:
```bash
python manage.py seed_users
```
کاربران پیش‌فرض ایجادشده:
* **نام:** مهتاب مروج | **ایمیل:** `mahtabmj96@gmail.com` | **موبایل:** `09224294833` | **رمز عبور:** `MahtabPass@123`
* **نام:** علی رضایی | **ایمیل:** `ali@gmail.com` | **رمز عبور:** `AliPass@123`
* **نام:** مریم حسینی | **ایمیل:** `maryam@gmail.com` | **رمز عبور:** `MaryamPass@123`

### ۳. اجرای سرور توسعه
```bash
python manage.py runserver
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **http://127.0.0.1:8000/**

## ۴. اجرای آزمون‌های خودکار (Automated Tests)

۱۰ آزمون خودکار برای اعتبارسنجی کلیه حالت‌های خواسته شده در صورت تمرین نوشته شده است. برای اجرای آن‌ها:
```bash
python manage.py test accounts
```
نتایج تست‌ها:
* اعتبارسنجی ثبت‌نام موفق و هش شدن رمز با الگوریتم PBKDF2
* رد ایمیل تکراری در ثبت‌نام
* رد عدم تطابق رمز و تکرار آن
* ورود موفق و حفظ سشن کاربری
* نمایش خطای کلی و یکسان برای رمز یا ایمیل نادرست
* محافظت از صفحه خوش‌آمدید در برابر دسترسی بدون احراز هویت
* خروج و ابطال نشست
* عدم افشای ایمیل در بازیابی رمز
* جریان کامل تغییر رمز با توکن زمان‌دار و ابطال لینک پس از یک‌بار استفاده

## ۵. فاز پایگاه داده (Assignment 02)

اسکریپت‌های طراحی پایگاه داده PostgreSQL در پوشه `database/` قرار دارند:
* `database/schema.sql`: ساختار جداول، کلیدها، محدودیت‌ها و تریگرها
* `database/seed.sql`: داده‌های نمونه و شبیه‌سازی اولیه
* `database/queries.sql`: کوئری‌های خواسته شده در صورت تمرین
* `database/tests.sql`: سناریوهای تست محدودیت‌ها
* `docs/erd.png`: تصویر نمودار ERD
* `docs/erd.md`: مستند توضیحات جداول و روابط
* `docs/jira-backlog.md`: تسک‌های مدیریت پروژه جیرا
